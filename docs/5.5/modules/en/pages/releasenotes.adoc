[#_v555_october_2026]
== v5.5.5 October 2026

=== Notable changes

To scan the latest PHP-related vulnerabilities, please restart all NeuVector scanner pods in order to use the latest version (CVE DB version 4.308 or newer).

=== Bugs Fixed

* **NVSHAS-10342**: NeuVector ConfigMap Watch Loop causing WAN Link Saturation (200 Mbps) & kube-apiserver instability.
* **issue-1349**: cli command cannot make controller write k8s-related debug logs.
* **fix**: automated federation join failed with controller ha setup.
* **fix**: add php version check.
* **Chore(deps)**: Update dependencies.
* **Chore(deps)**: Upgrade golang to 1.27.3.

[#_v554_september_2026]
== v5.5.4 September 2026

=== Enhancement

* **Issue-2423**: Prevent the cvedb `is empty` case.
* **Issue-2602**: Provide vcs information in NeuVector's golang binaries.

=== Bugs Fixed

* **NVSHAS-10289**: Group contention resolution Restrict Mode on K3s/RKE2 yields unexpected results.
* **Issue-2669**: Suppress log messages Benchmark report not found.
* **Issue-2686**: Duplicate response rules are created when importing (through CRD) same-name response rules with changes.
* **Issue-2709**: When CRD-defined response rules are triggered, the webhook call (if configured) is not sent.
* **Issue-2727**: NV doesn't prevent user from importing federated groups/policies through CRD.
* **Chore(deps)**: Dependency updates & golang upgrade.
