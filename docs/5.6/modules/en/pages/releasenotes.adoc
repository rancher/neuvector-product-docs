[#_v564_october_2026]
== v5.6.4 October 2026

[NOTE]
.Critical CVE Stats After Upgrade
====
Upgrading to {neuvector-product-name} v5.6.4 or later from any version prior to v5.6.0 requires all existing {neuvector-product-name} scanner pods to be restarted or redeployed to support the CVE critical-level severity.

Older scanner pods cache the controller's initial capability response. They will not recognize that the upgraded controller supports critical-level severity until they are restarted and re-query the controller on startup.
====

=== Notable changes

To scan the latest PHP-related vulnerabilities, please restart all NeuVector scanner pods in order to use the latest version (CVE DB version 4.308 or newer).

=== Bug fixes

* **NVSHAS-10342**: NeuVector ConfigMap Watch Loop causing WAN Link Saturation (200 Mbps) & kube-apiserver instability.
* **issue-1349**: cli command cannot make controller write k8s-related debug logs.
* **fix**: add php version check.
* **Chore(deps)**: Update dependencies.
* **Chore(deps)**: Upgrade golang to 1.27.3.
